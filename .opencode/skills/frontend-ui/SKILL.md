# Frontend UI Skill

Use this skill when creating or modifying user interfaces.

## Component selection

Before creating a component from scratch:

1. Check whether shadcn/ui provides it.
2. If not, check existing project components.
3. Only then create a custom component.

## Visual design

- Use a restrained color palette.
- Establish a clear visual hierarchy.
- Use consistent spacing.
- Prefer subtle borders and shadows.
- Avoid excessive gradients.
- Avoid excessive glassmorphism.
- Use animation only when it improves the experience.

## Interactions

Use Motion for:
- page transitions
- expanding/collapsing elements
- modal animations
- list enter/exit animations
- subtle hover interactions

Do not animate everything.

## Icons

Use Lucide React.
Never use emojis as interface icons.
